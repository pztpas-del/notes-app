# Заметки

Простая программа для заметок в духе Obsidian: заметки со ссылками `[[Название]]`, теги `#тег`, обратные ссылки, граф связей и синхронизация между устройствами через ваш GitHub.

- Каждая заметка — обычный текстовый файл `.md`. Все они лежат в вашем закрытом хранилище на GitHub с полной историей изменений.
- Программа работает и без интернета: изменения отправятся, когда связь появится.
- От Claude она не зависит. Это обычный сайт, который можно открыть в браузере или поставить на телефон как приложение.

## Что умеет

| Действие | Как |
|---|---|
| Живой просмотр | Разметка оформляется прямо при наборе: значки `#`, `**`, `[[ ]]` видны только на строке, которую вы сейчас правите |
| Ссылка на другую заметку | `[[Название]]`; после `[[` появляется подсказка. `[[Название\|текст]]` меняет текст ссылки |
| Перейти по ссылке | Нажать на ссылку; на строке, которую правите, — Ctrl + щелчок |
| Картинки и файлы | Кнопка со скрепкой, вставка из буфера (Ctrl+V) или перетаскивание в заметку. Файлы хранятся на вашем Яндекс Диске в папке «Приложения/Заметки» и скачиваются на устройство, только когда вы их открываете (недавние запоминаются, до 300 МБ). Подключение — в настройках, раздел «Яндекс Диск», на каждом устройстве один раз. Большие фото уменьшаются до 2000 точек. В тексте это выглядит как `![[имя файла]]` |
| Поиск по заметке | Ctrl+F |
| Создать заметку по ссылке | Нажать на ссылку на несуществующую заметку |
| Папки | В названии заметки написать `Папка/Название` |
| Переименовать | Изменить название вверху; ссылки в других заметках обновятся сами |
| Режим чтения и правки | Кнопка вверху справа или Ctrl+E |
| Граф связей | Кнопка в списке заметок или Ctrl+G; колёсико или два пальца меняют масштаб. Связи из блок-схемы в графе тоже видны |
| Панель справа | Кнопка с двумя половинками вверху справа показывает рядом с открытой заметкой её граф связей (галочка «Все заметки» — весь граф) или блок-схему с подсвеченной заметкой. Ширину панели можно менять, потянув за левый край; на узком экране панель выезжает поверх заметки |
| Блок-схема | Кнопка со схемой в списке заметок. «+ Заметки» добавляет заметки на схему. Связь: потянуть за кружок под блоком к другому блоку; отпустить на пустом месте — создать новую заметку ниже. Блоки раскладываются по уровням сами; перетащенный блок запоминает место, «Выровнять» раскладывает всё заново. Двойной щелчок (на телефоне — второе нажатие) открывает заметку, Delete удаляет выбранную связь или убирает блок со схемы. Схема хранится в файле `Схема.canvas` (формат JSON Canvas), заметки при этом не меняются |
| Календарь | Кнопка с календарём в списке заметок. Виды «День», «Неделя», «Месяц», «Расписание»; мини-календарь; календари-категории со своими цветами (по умолчанию «Учёба», «Дела», «Отдых»), их можно включать и выключать, добавлять свои. События: время или весь день, повторы (каждый день, по будням, по дням недели, по числу или дню недели месяца, каждый год, свой интервал, до даты или N раз), место, описание, цветная и текстовая метка. Повторяющееся событие можно изменить или удалить только одно или всю серию. Новое событие — кнопкой или протягиванием мышью по сетке; перетаскивание переносит событие, нижний край меняет длительность. Поиск по событиям, праздники России, рабочие часы, список дел со сроками, импорт и экспорт .ics (совместимо с Яндекс и Google Календарём). События хранятся в папке «Календарь» хранилища заметок и в заметки не попадают |
| Напоминания | У каждого события — сколько угодно напоминаний: от «в момент начала» до «за неделю» или своё время; у каждого календаря — свои напоминания по умолчанию. Приходят уведомлением, пока программа открыта или недавно свёрнута; пропущенные за 6 часов показываются при открытии. Утром — список дел на день (время настраивается). Разрешить уведомления: Календарь → Настройки календаря |
| Поиск | Поле над списком; `#тег` ищет по тегу; Ctrl+O переходит в поиск |
| Список заметок | Всегда слева, как в Obsidian; ширину можно менять, потянув за правый край (двойной щелчок по краю возвращает обычную ширину). Кнопка в правом верхнем углу списка скрывает его, кнопка ☰ показывает снова. На телефоне список выезжает поверх |
| Новая заметка | Кнопка «+» или Alt+N |
| Синхронизировать сейчас | Ctrl+S или кнопка состояния внизу списка |

Ещё поддерживается обычная разметка: заголовки, списки, задачи `- [ ]`, цитаты, выноски `> [!tip]`, таблицы, код, `**жирный**`, `*курсив*`, `==выделение==`.

## Если заметку изменили на двух устройствах сразу

Ничего не теряется. Ваша версия остаётся в заметке, а версия с другого устройства сохраняется рядом как «Название (конфликт дата).md». Сравните их, перенесите нужное и удалите копию.

## Установка (один раз)

1. **Хранилище для заметок.** На GitHub создайте закрытое (Private) хранилище, например `notes`, и при создании отметьте *Add a README file*.
2. **Токен.** Откройте https://github.com/settings/personal-access-tokens/new и создайте токен:
   - *Repository access*: *Only select repositories*, выберите хранилище заметок;
   - *Repository permissions → Contents*: *Read and write*.
3. **Сама программа.** Создайте открытое хранилище, например `notes-app`, загрузите в него содержимое этой папки (программа лежит в `docs`) и включите *Settings → Pages* (ветка `main`, папка `/docs`). Через минуту программа будет доступна по адресу вида `https://имя.github.io/notes-app/`. В этом хранилище только код программы, заметок там нет.
4. **На каждом устройстве** откройте этот адрес, нажмите шестерёнку и введите имя пользователя GitHub, название хранилища заметок и токен.
5. **На Android** откройте адрес в Chrome, затем меню ⋮ → *Добавить на главный экран* (или *Установить приложение*).

Токен хранится только на том устройстве, где его ввели. Если токен истёк, создайте новый и введите его в настройках.

## Для разработки

```bash
node dev/serve.js
```

Откроется на http://localhost:5173. Сервер заодно имитирует GitHub по адресу `/mock-github`: в настройках раскройте «Для разработки», укажите адрес API `http://localhost:5173/mock-github`, а в остальные поля впишите что угодно. Иконки пересоздаются командой `node dev/make-icons.js`.

Устройство кода:

- `docs/js/vault.js` — заметки на устройстве, ссылки, переименование, граф;
- `docs/js/sync.js` — синхронизация заметок с GitHub;
- `docs/js/yadisk.js`, `docs/js/media.js` — картинки и файлы на Яндекс Диске, скачивание при открытии;
- `docs/js/markdown.js` — отображение разметки;
- `docs/js/graph.js` — граф связей;
- `docs/js/schema.js` — блок-схема и её раскладка по уровням;
- `docs/js/calendar.js`, `docs/js/calendar-data.js` — календарь: виды, события, повторы, напоминания, дела, .ics;
- `docs/js/editor.js` — редактор с живым просмотром (на основе CodeMirror, собран в `docs/vendor/codemirror.js` командой `npm run build:editor`);
- `docs/js/app.js` — интерфейс;
- `docs/sw.js` — работа без интернета.
