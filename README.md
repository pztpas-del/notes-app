# Заметки

Простая программа для заметок в духе Obsidian: заметки со ссылками `[[Название]]`, теги `#тег`, обратные ссылки, граф связей и синхронизация между устройствами через ваш GitHub.

- Каждая заметка — обычный текстовый файл `.md`. Все они лежат в вашем закрытом хранилище на GitHub с полной историей изменений.
- Программа работает и без интернета: изменения отправятся, когда связь появится.
- От Claude она не зависит. Это обычный сайт, который можно открыть в браузере или поставить на телефон как приложение.

## Что умеет

| Действие | Как |
|---|---|
| Ссылка на другую заметку | `[[Название]]`; после `[[` появляется подсказка. `[[Название\|текст]]` меняет текст ссылки |
| Перейти по ссылке | В режиме чтения просто нажать; в режиме правки Ctrl + щелчок |
| Создать заметку по ссылке | Нажать на ссылку на несуществующую заметку |
| Папки | В названии заметки написать `Папка/Название` |
| Переименовать | Изменить название вверху; ссылки в других заметках обновятся сами |
| Режим чтения и правки | Кнопка вверху справа или Ctrl+E |
| Граф связей | Кнопка в списке заметок или Ctrl+G; колёсико или два пальца меняют масштаб |
| Поиск | Поле над списком; `#тег` ищет по тегу; Ctrl+O переходит в поиск |
| Новая заметка | Кнопка «+» или Alt+N |
| Синхронизировать сейчас | Ctrl+S или кнопка состояния внизу списка |

Ещё поддерживается обычная разметка: заголовки, списки, задачи `- [ ]`, цитаты, выноски `> [!tip]`, таблицы, код, `**жирный**`, `*курсив*`, `==выделение==`.

## Если заметку изменили на двух устройствах сразу

Ничего не теряется. Ваша версия остаётся в заметке, а версия с другого устройства сохраняется рядом как «Название (конфликт дата).md». Сравните их, перенесите нужное и удалите копию.

## Установка (один раз)

1. **Хранилище для заметок.** На GitHub создайте закрытое (Private) хранилище, например `notes`, и при создании отметьте *Add a README file*.
2. **Токен.** Откройте https://github.com/settings/personal-access-tokens/new и создайте токен:
   - *Repository access*: *Only select repositories*, выберите хранилище заметок;
   - *Repository permissions → Contents*: *Read and write*.
3. **Сама программа.** Создайте открытое хранилище, например `notes-app`, загрузите в него содержимое этой папки (программа лежит в `docs`) и включите *Settings → Pages* (ветка `main`, папка `/docs`). Через минуту программа будет доступна по адресу вида `https://имя.github.io/notes-app/`. В этом хранилище только код программы, заметок там нет.
4. **На каждом устройстве** откройте этот адрес, нажмите шестерёнку и введите имя пользователя GitHub, название хранилища заметок и токен.
5. **На Android** откройте адрес в Chrome, затем меню ⋮ → *Добавить на главный экран* (или *Установить приложение*).

Токен хранится только на том устройстве, где его ввели. Если токен истёк, создайте новый и введите его в настройках.

## Для разработки

```bash
node dev/serve.js
```

Откроется на http://localhost:5173. Сервер заодно имитирует GitHub по адресу `/mock-github`: в настройках раскройте «Для разработки», укажите адрес API `http://localhost:5173/mock-github`, а в остальные поля впишите что угодно. Иконки пересоздаются командой `node dev/make-icons.js`.

Устройство кода:

- `docs/js/vault.js` — заметки на устройстве, ссылки, переименование, граф;
- `docs/js/sync.js` — синхронизация с GitHub;
- `docs/js/markdown.js` — отображение разметки;
- `docs/js/graph.js` — граф связей;
- `docs/js/app.js` — интерфейс;
- `docs/sw.js` — работа без интернета.
