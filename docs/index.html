Синхронизация

Заметки хранятся обычными .md-файлами в вашем закрытом хранилище на GitHub. На каждом устройстве введите одни и те же данные.

Для разработки

Где взять токен

  1. Создайте на GitHub закрытое хранилище для заметок и при создании отметьте Add a README file.
  2. Откройте Fine-grained tokens → Generate new token.
  3. В Repository access выберите Only select repositories и укажите хранилище заметок.
  4. В Repository permissions для Contents выберите Read and write.
  5. Задайте срок действия, создайте токен и вставьте его сюда. Токен хранится только на этом устройстве.

Нет открытой заметки

Выберите заметку в списке или создайте новую.
